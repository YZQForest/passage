# Passage 0.1.0 开发版交付与验收

交付日期：2026-10-04。本次按照完整提示词的阶段安排，先完成 67 项设计评审，再实现第一阶段阅读闭环，并提前实现部分第二、第三阶段功能。这是首个可安装开发版；不代表完整提示词的全部要求已经实现。

## 已实现

- 文献库：本地 PDF 导入、SHA-256 去重、受管副本、置顶与删除。不会改写原始 PDF。
- 阅读：原始 PDF 画布与官方 TextLayer、连续/单页模式、缩放、全文搜索、章节列表、活动段落、文本选择、阅读位置/模式恢复。仅按视口附近渲染，离屏页释放画布。
- AI：选择文本或段落翻译、解释、公式文本解释、段落总结、单篇论文问答；流式显示、主动停止、超时、错误反馈。无 Key 时明确提示配置，不生成假结果。
- 证据：本地词项检索选择有限上下文，回答中的有效 [S#] 映射到所提供的论文段落；来源预览、主动跳转、阅读前进/后退。没有跨论文检索与向量数据库。
- 保护与缓存：公式、引文、专有名词占位保护，严格检查遗漏/重复；术语覆盖；持久化翻译缓存随原文、模型、服务地址、术语和提示词版本失效。未接入语义正确性自动判定。
- 阅读辅助：双语栏、Alt 临时译文预览、专注模式；选中段落按需翻译。默认不做后台预取。
- 本地资料：笔记、AI 内容存为笔记、引用原文、选文高亮与最近高亮撤销、术语表、问答历史、书签、完整资料导出（含受管 PDF、不含 API Key）。
- 用量：独立用量窗口，请求明细、会话/今日/7天/30天/全部筛选，实际/估算 Token 区分，缓存与推理 Token 字段，用户填写的价格估算，以及请求前每日 Token 硬限制。
- 平台：共享 UI 与领域逻辑；桌面受限 IPC、SQLite worker、系统密钥加密；Android 原生 SQLite、KeyStore、系统文件选择器和原生流式 HTTP。数据库有版本迁移与桌面迁移前备份。

## 已执行验收

1. 单元/集成测试：3 个测试文件、19 个测试通过；包括占位保护、缓存失效、来源白名单、阅读导航、双栏段落 bbox、分片 UTF-8/SSE、服务商 usage 归一化、HTTP 错误、端点安全、价格估算、流截断、SQLite 重启/删除关联/迁移。
2. 类型检查、代码检查、格式检查和生产构建通过；npm audit 没有已报告漏洞。
3. 桌面应用：24 页专用双栏测试 PDF，以及 15 页真实论文 Attention Is All You Need。验证 PDF/TextLayer、搜索、选文、高亮撤销、笔记、SQLite 持久化与第 9 页快速退出后的恢复；渲染器没有未处理异常。
4. 桌面 AI 协议验收：明确标记的本地 SSE 服务，覆盖翻译、公式/引文/术语保护、缓存不重复请求、解释、论文问答、来源预览、存笔记、用量、取消和硬限制。没有上传整篇 PDF。
5. Android：原生文件选择器导入 24 页 PDF、画布与文本层、KeyStore 加密后的凭据在文件中不含明文、原生 HTTP 流式翻译、缓存、笔记和杀进程重启后的第 7 页恢复通过。Android 15 模拟器的 Chrome 124 WebView 发现兼容问题后，切换 PDF.js legacy 构建并重新通过测试。
6. Android `assembleDebug`、`bundleRelease`、`lintDebug` 成功；保留第三方 Gradle flatDir/升级建议等警告，不隐藏检查结果。

**AI 验收使用协议测试服务，不是真实模型效果验收。** 没有用户的真实 API Key，因此未完成各服务商联网、模型兼容性、计费准确性和翻译质量的真实验收。主界面与正式文献库不预置演示论文或虚构 AI 输出。
